# Numeral recognition masks

`native_digit_templates.npz` contains tiny binary glyph masks for recognizing **already existing** native 1–4 gaze markers. They were sampled in the earlier local workflow; provenance is retained in `template-provenance.json`. They contain no source photographs, account information or native report archives, and do not generate gaze locations.

The masks are functional recognition references, not a license to redistribute 3M interface artwork. Third-party glyph/interface rights are not transferred by this repository’s MIT license. The surrounding annotation code is original local workflow code integrated for this skill; full report images and case-specific repairs remain outside the package.
