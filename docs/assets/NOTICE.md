# Third-party teaching illustrations

The three JPEGs in this directory were extracted without alteration from page 5 of the user-supplied handbook *Living Structure + AI: Four Hands-On Exercises for Exploring and Assessing Wholeness*, by **Hongkai Zhang and Bin Jiang**. The source PDF itself is not distributed.

- `handbook-vas-workflow.jpg`: historical 3M VAS website workflow screenshot montage.
- `handbook-combined-scan.jpg`: historical combined-analysis example.
- `handbook-separate-scans.jpg`: historical separate-analysis examples.

These are attributed teaching excerpts added at the user's request.
